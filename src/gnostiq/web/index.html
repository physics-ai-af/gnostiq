Gnostiq

Global model forecasts corrected for one site, with uncertainty, checked against observations the model never saw.

Skill is how much lower Gnostiq's error is than another system's, on the same reports. Above zero, Gnostiq is better. The range shows how sure that is: a range that crosses zero means the two are tied on the evidence so far. The bar that matters is the best alternative, not the raw model Gnostiq starts from.
